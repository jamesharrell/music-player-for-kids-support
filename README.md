# Review Web Pages

These pages are hosted at live HTTPS URLs for App Review:

- Support URL: `https://jamesharrell.github.io/music-player-for-kids-support/support.html`
- Privacy Policy URL: `https://jamesharrell.github.io/music-player-for-kids-support/privacy.html`
- Source repo: `https://github.com/jamesharrell/music-player-for-kids-support`

Local source files:

- `index.html` links to support and privacy.
- `support.html` is for the App Store Connect Support URL.
- `privacy.html` is for the App Store Connect Privacy Policy URL.

The pages use the support email from local git config: `james@harrell.dev`. Do not submit local file paths to App Store Connect. Apple flags broken or missing support/privacy links under App Completeness and privacy review.
