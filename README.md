# Review Web Pages

Host these pages at live HTTPS URLs before submitting to App Review:

- `support.html` for the App Store Connect Support URL.
- `privacy.html` for the App Store Connect Privacy Policy URL.
- `index.html` as a small landing page linking to both.

The pages use the support email from local git config: `james@harrell.dev`.

Do not submit local file paths to App Store Connect. Apple flags broken or missing support/privacy links under App Completeness and privacy review.
